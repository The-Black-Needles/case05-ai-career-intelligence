# Case 05 Public Blueprint

## Identity

**Case 05 — AI Career Intelligence — Intelligent Job Opportunity Decision System**

AI Career Intelligence is the proposed system boundary. AI Job Radar is a
prospective module/concept inside that broader system; it is not an active
product or operational module in this repository.

## Publication status

**PUBLIC SCAFFOLD ONLY**

### IMPLEMENTED

- Public identity and status documentation
- Package metadata
- Synthetic example configuration
- Empty reference-job dataset
- Scaffold-level tests

### PLANNED / NOT ACTIVE

The target architecture may eventually include authorized collection,
normalization, identity resolution, deduplication, eligibility gates, semantic
classification, evidence matching, scoring, Candidate Readiness, LLM evaluation,
report generation, security enforcement, agents, and a Decision Model runtime.
None of those capabilities is implemented or active here.

## Target architecture

Every stage in this target flow is **PLANNED / NOT ACTIVE**:

1. Authorized-source collection
2. Normalization and identity resolution
3. Cross-run deduplication
4. Deterministic eligibility gates
5. Semantic role classification
6. Candidate-evidence matching and Candidate Readiness assessment
7. Explainable decision scoring
8. Confidence assessment and LLM evaluation
9. Incremental reporting
10. Human review

This list records design intent only. It is not evidence of executable code,
operational validation, enforcement, or production experience.

## Public/private boundary

Any future public demonstration should use only synthetic or deliberately
sanitized profiles, companies, jobs, reports, and evaluation data. It should
exclude credentials, authentication material, application history, confidential
project or corporate information, proprietary material, and private repository
history.

## Truthful publication gates

Future capabilities should be described as implemented only after corresponding
code and proportionate tests are present in the public repository. Operational
claims would additionally require reproducible evidence appropriate to the
claim. Planned safeguards must not be described as enforced before enforcement
exists.

Possible future publication evidence includes deterministic regression tests,
a populated synthetic or sanitized reference dataset, a sanitized demonstration
report, and documented validation of any implemented collection, deduplication,
change detection, and security controls. These are publication criteria, not
current achievements.
