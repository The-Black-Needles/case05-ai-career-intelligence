# Case 06 Public Blueprint

## Product

**AI Job Radar — Agentic Career Opportunity Intelligence**

## Purpose

Build a public portfolio case that demonstrates responsible use of AI agents, business automation, software engineering, data processing, security controls, evaluation and human-in-the-loop decision support.

## Public and private separation

The public repository must never contain:

- Real application history
- Personal career preferences that are not required for demonstration
- Private company assessments
- Confidential project information
- Corporate data
- Authentication material
- Local credentials
- Proprietary prompts or architectures
- Private repository history

The public version will use synthetic or sanitized:

- Candidate profiles
- Companies
- Job descriptions
- Application history
- Reports
- Evaluation datasets

## Target architecture

1. Authorized-source collection
2. Normalization
3. Identity resolution
4. Cross-run deduplication
5. Deterministic eligibility gates
6. Semantic AI-role classification
7. Candidate-evidence matching
8. Explainable scoring
9. Confidence assessment
10. Weekly incremental reporting
11. Human review

## Engineering capabilities to demonstrate

- Modular Python architecture
- Typed domain models
- Unit and integration tests
- Structured outputs
- Prompt versioning
- LLM evaluation
- Token and latency monitoring
- Retries and fallbacks
- Domain allowlists
- Audit trails
- CI validation
- Secure configuration
- Incremental processing

## Initial publication criteria

The first public release should occur only after:

- Three successful operational cycles
- Deduplication across executions
- Material-change detection
- Domain allowlist enforcement
- Safe handling of CAPTCHA, authentication and rate limits
- Scoring Model V2 validation
- A labeled reference-job dataset
- Deterministic regression tests
- A sanitized demonstration report
- Repository secret scanning
